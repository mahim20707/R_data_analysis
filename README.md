# Data Analysis using tapply()

## About This Project
This project analyzes students marks based on gender using R Programming and the **tapply()** function.

## Objectives
- Read and Analyze marks data.
- Groups students according to gender.
- Calculate Statistical value using **tapply()**.
  
## Analyzed Perform
- Maximum Marks
- Minimum Marks
- Mean(Average) Marks
  
## Tools used
- R Programming
- Rstudio
- tapply()
